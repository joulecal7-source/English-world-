LESSON 7.5 — EXERCICES

Pratique des 3 Formes

60 phrases — Present, Passe Simple, Passe Compose

Teacher Joule bin Musuwa • EnglishWorld
Serie 1 : Sentiments — To Be
Structure : Sujet + AM/IS/ARE (present) → WAS/WERE (passe) → HAVE/HAS BEEN (passe compose)
I am happy → I was happy → I have been happy
Je suis heureux → J etais heureux → J ai ete heureux
Aline is sad → Aline was sad → Aline has been sad
Aline est triste → Aline etait triste → Aline a ete triste
Joule is ready → Joule was ready → Joule has been ready
Joule est pret → Joule etait pret → Joule a ete pret
They are tired → They were tired → They have been tired
Ils sont fatigues → Ils etaient fatigues → Ils ont ete fatigues
We are strong → We were strong → We have been strong
Nous sommes forts → Nous etions forts → Nous avons ete forts
Serie 2 : Mouvement — Go, Come, Run
I go to Kinshasa → I went → I have gone
Je vais → Je suis alle → Je suis alle a Kinshasa
Eric comes from Goma → Eric came → Eric has come
Eric vient → Eric est venu → Eric est venu de Goma
Musuwa runs fast → Musuwa ran → Musuwa has run
Musuwa court → a couru → a couru vite
They go home → They went home → They have gone home
Ils vont → sont alles → sont alles a la maison
Serie 3 : Vie Quotidienne — Eat, Drink, Sleep
I eat an apple → I ate → I have eaten
Je mange → J ai mange → J ai mange une pomme
Brigitte drinks water → Brigitte drank → Brigitte has drunk
Brigitte boit → a bu → a bu de l eau
The baby sleeps → The baby slept → The baby has slept
Le bebe dort → a dormi → a dormi
We eat at the restaurant → We ate → We have eaten
Nous mangeons → avons mange → avons mange au restaurant
Serie 4 : Communication — Write, Speak, Do
Joule writes a book → Joule wrote → Joule has written
Joule ecrit → a ecrit → a ecrit un livre
Aline speaks English → Aline spoke → Aline has spoken
Aline parle → a parle → a parle anglais
I do my work → I did → I have done
Je fais → ai fait → ai fait mon travail
They see the airport → They saw → They have seen
Ils voient → ont vu → ont vu l aeroport
Serie 5 : Possession — Have, Know, Understand
I have a car → I had a car → I have had a car
J ai → j avais → j ai eu une voiture
Paul knows the way → Paul knew → Paul has known
Paul connait → connaissait → a connu le chemin
We understand the lesson → We understood → We have understood
Nous comprenons → avons compris → avons compris la lecon
Note importante : Pour le passe compose en anglais, utilisez toujours HAVE/HAS + 3eme forme du verbe irregulier. Ex: have eaten, have gone, have written...
